## Project Overview

Cryptographic assessment and migration tool for transitioning enterprise systems to quantum-resistant algorithms. Scans infrastructure for vulnerable cryptographic implementations and provides migration paths to post-quantum alternatives.

**Role**: IT Operations Specialist
**Organization**: ACORIA
**Duration**: February 2020 - June 2020
**Project**: #20 of 30 in IT Career Portfolio

## Business Impact

- **Full Cryptographic Inventory**: Automated discovery across infrastructure
- **Risk Assessment**: Vulnerability scoring for quantum threats
- **Migration Roadmap**: Prioritized transition plan
- **Future-proof Security**: NIST PQC candidate implementations

## Technology Stack

- **Python 3.8**: Core scanning and migration engine
- **Post-Quantum Cryptography**: CRYSTALS-Kyber, CRYSTALS-Dilithium
- **OpenSSL 1.1**: Certificate and key management
- **liboqs**: Open Quantum Safe library
